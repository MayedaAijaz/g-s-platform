# GS Medcure — Digital Manufacturing Intelligence Platform

> ⚠️ **PROOF OF CONCEPT / DEMO APPLICATION**
> All operational data is **SYNTHETIC** and is generated by the seed script.
> This application is not connected to any real G&S Medcure internal systems,
> production data, suppliers, or regulatory filings.
> Public references are limited to the name "G&S Medcure", "Rashakai SEZ" location,
> and publicly available DRAP product names (NEOPRO syringes).

---

## Stack

| Layer | Technology |
|---|---|
| Frontend | React 18 + Vite + TypeScript + Tailwind CSS |
| State / Data | TanStack Query v5 |
| Charts | Recharts |
| Backend | Node.js + Express + TypeScript |
| ORM | Prisma 5 |
| Database | PostgreSQL 16 |
| Validation | Zod (shared between frontend & backend) |
| Auth | JWT (bcrypt passwords) |
| Testing | Vitest + Supertest |
| DevOps | Docker Compose |

---

## Quick Start (Docker Compose)

```bash
# 1. Clone and enter directory
cd gs-medcure

# 2. Copy env template
cp .env.example .env
# Edit .env to set a strong JWT_SECRET

# 3. Start everything
docker compose up --build

# 4. Run migrations & seed
docker compose exec api npx prisma migrate dev
docker compose exec api npm run db:seed
```

App will be at http://localhost:5173
API will be at http://localhost:4000

---

## Local Development (without Docker)

**Prerequisites:** Node 20+, PostgreSQL 16, npm 10+

```bash
cd gs-medcure
cp .env.example .env
# Edit DATABASE_URL, JWT_SECRET

npm install          # installs all workspaces

# Run migrations
npm run db:migrate

# Seed synthetic demo data
npm run db:seed

# Start both API and web (concurrent)
npm run dev
```

## Batch State Machine

```
DRAFT → IN_PRODUCTION → QC_HOLD → RELEASED
                       ↘ REJECTED
IN_PRODUCTION → REJECTED
```

- RELEASED requires at least one PASSED QC inspection
- QC results are immutable once submitted
- All transitions are audit logged

## Deployment (Render)

1. Push to GitHub.
2. Create a Render PostgreSQL instance → copy `DATABASE_URL`.
3. Create a Render Web Service for `apps/api`:
   - Build: `npm install && npx prisma generate && npm run build`
   - Start: `npx prisma migrate deploy && node dist/index.js`
   - Env: `DATABASE_URL`, `JWT_SECRET`, `NODE_ENV=production`
4. Create a Render Static Site for `apps/web`:
   - Build: `npm install && npm run build`
   - Publish dir: `apps/web/dist`
   - Set `VITE_API_URL` to the Render API URL.
